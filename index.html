Unduh Nalara

  1. Unduh aplikasinya

    Tekan tombol Unduh. File app-release.apk akan diunduh melalui browser ke perangkat Anda.

  2. Pasang di ponsel Android

    Buka file APK dari folder Unduhan. Jika Android meminta izin pemasangan dari browser, berikan izin untuk sumber yang Anda percaya, lalu ikuti petunjuk di layar.

  3. Kenalkan toko Anda

    Daftar atau masuk, lengkapi informasi toko, dan tambahkan produk. Anda siap mencatat transaksi pertama.

Sebelum mulai

Masih ingin tahu?

Apakah Nalara bisa dipakai di semua ponsel?

Nalara tersedia untuk ponsel Android versi 7.0 atau lebih baru. File APK ini tidak dapat dipasang di iPhone. Jika Anda membuka halaman ini dari komputer, pindahkan file yang diunduh ke ponsel Android.

Apakah aplikasi memerlukan internet?

Ya. Siapkan koneksi internet untuk masuk ke akun, menyimpan transaksi, dan menyinkronkan data toko. Dengan begitu, data yang tampil dapat mengikuti perubahan terbaru.

Apakah QRIS langsung memproses pembayaran?

Nalara mencatat pembayaran QRIS secara manual. Pelanggan membayar melalui QRIS toko Anda di luar aplikasi. Periksa bahwa pembayaran sudah diterima sebelum mencatat transaksi di Nalara.

Apa perbedaan Basic dan Premium?

Basic mencakup kasir, produk, stok, riwayat transaksi, ringkasan usaha, dan ekspor laporan. Premium menambahkan laporan terperinci dan analisis usaha. Pada versi demo saat ini, Premium dapat diaktifkan selama 30 hari tanpa pembayaran melalui menu Paket Nalara.

File sudah diunduh, tetapi belum terpasang?

Mengunduh APK dan memasangnya adalah dua langkah berbeda. Buka app-release.apk melalui folder Unduhan, lalu pilih Pasang. Pastikan ruang penyimpanan cukup dan periksa petunjuk yang ditampilkan oleh Android.
